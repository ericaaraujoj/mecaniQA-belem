# MecâniQA - Automotive Tech

## Sobre o Projeto

Projeto desenvolvido pela equipe durante o programa de trainee da **MecâniQA - Automotive Tech**, empresa fictícia criada para o desenvolvimento das atividades práticas da disciplina.

O projeto tem como foco a aplicação de **Ciência de Dados** na análise e previsão de demanda de manutenções automotivas, utilizando dados históricos de **trocas de óleo e manutenções de motor**.

## 🎯 Objetivo

Analisar o comportamento histórico das manutenções e desenvolver uma base para previsão de demanda.

Nesta etapa, trabalhamos com:

- Limpeza e preparação dos dados;
- Tratamento de valores ausentes e outliers;
- Análise exploratória de séries temporais;
- Identificação de tendências e sazonalidade;
- Modelos baseline **Naive** e **Média Móvel**.
